### 🛠️ What I build

**🔹 API regression framework for a microservices platform**
Cucumber BDD + TestNG + REST Assured (Java) suite covering 10 services across three AWS environments. Led a full refactor: thread-safe shared test state for parallel runs, upgraded dependencies, consolidated runners, and externalized environment config.

**🔹 QA execution dashboard**
Interactive dashboard and editable Excel report generated from Cucumber HTML results across 9 services — one view of pass/fail health for the whole platform.

**🔹 AI-assisted test design**
Workflows that turn Jira stories, Swagger specs, screen recordings, and DB/log screenshots into structured, import-ready test cases for test management tools — cutting authoring time per sprint.

**🔹 Testing AI in production**
Validation of LLM-driven sentiment/intent tagging and agent-based feedback triage — making sure the model labels real passenger feedback correctly.

**🔹 Event-driven & integration testing**
RabbitMQ / SQS / SNS message flows, flight-event pipelines (multi-leg, departure/arrival events), feature-flag-gated rollouts, and contract testing concepts (Pact / CDC) for message-based services.

**🔹 Scalable UI & cross-browser automation**
Page Object Model and hybrid/data-driven frameworks in Selenium (Java & Python) and Cypress, run in parallel on Selenium Grid with Docker and AWS EC2.
